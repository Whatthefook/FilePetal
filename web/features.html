What FilePetal does

Three wheels for everyday file work.

Hold a modifier while dragging on Windows. On macOS and Linux, use the companion window and choose a wheel. Options depend on the file type and installed engines.

ConvertToolsFile actions
01

Shift

Convert

FilePetal shows outputs supported for the selected file. It doesn’t offer a conversion just because two formats look similar.

  • Images, audio, video, PDFs, documents, spreadsheets, slides, subtitles, ePub, and archives.
  • Examples: JPG to WebP or PDF; PDF to DOCX, text, JPG, or PNG; MP4 to WebM, GIF, or MP3; SRT to VTT.
  • Some audio and video work requires FFmpeg and FFprobe installed locally.

02

Alt + Shift

Focused tools

Open a tool for the selected file family. Original files stay untouched; outputs are written separately.

Images

Compress, edit, inspect or remove metadata, annotate, add a background, crop, redact, make a PDF, or build a collage.

Video

Compress, inspect metadata, trim, crop, change speed, remove audio, extract snapshots, split, join, or redact.

Audio

Compress, inspect tags, normalize loudness, trim, change channels, bleep a section, or make a waveform video.

PDF and archives

Compress or split PDFs, merge several PDFs, create a PDF from images, and safely extract archives.

03

Ctrl + Shift

File actions

Use quick operating-system actions without opening several menus.

  • Float: pin files to a small shelf so they’re easy to drag elsewhere.
  • Copy files: put file references on the clipboard for pasting into another app.
  • Move: choose a destination; name conflicts get a safe numbered name.
  • Copy path: copy the selected files’ full paths.
  • Terminal: open the containing folder in Windows Terminal or PowerShell on Windows.
  • Share: use Windows’ system share interface where the file type supports it.
