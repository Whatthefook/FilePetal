How It Works

One gesture. Three powerful wheels.

FilePetal sits quietly in your system tray. Whenever you drag files, hold a modifier key to invoke the radial dial right at your cursor.

Shift

Convert Wheel

Presents only genuine, compatible output formats for your selected file types. No broken or fake conversions:

  • Images: PNG, JPG, WebP, AVIF, SVG, ICO, BMP, TIFF
  • Video: MP4, WebM, GIF, MKV, AVI, MOV
  • Audio: MP3, WAV, AAC, OGG, FLAC, M4A
  • Documents: DOCX, PDF, XLSX, TXT, EPUB
  • Subtitles: SRT ↔ VTT
Alt + Shift

Tools Wheel

Routes selected items directly into fast, focused local editors and background processing jobs:

  • Photo tools: Crop, Redact, Annotate, Background color, Exif metadata
  • Video tools: Trim, Crop, Adjust speed, Extract frames, Redact boxes
  • Audio tools: Normalize volume, Generate waveform video, Trim, Channel mixing
  • PDF tools: Merge multiple PDFs, Split pages, Images-to-PDF
  • Archives: Safe extraction with path-traversal safeguards
Ctrl + Shift

File Actions Wheel

Take fast operating-system actions on the selected files without opening full menus:

  • Float Files: Pin files to a small floating shelf to drag elsewhere later
  • Move to Folder: Safely relocate files with automated collision prevention
  • Copy References: Place file handles onto clipboard for pasting
  • Copy Paths: Grab absolute file paths in one click
  • Terminal: Open Windows Terminal / PowerShell at the folder location
  • System Share: Invoke native Windows Share interface
Focused Tool Editors Compact frosted-glass dialogs for precise, local photo and video adjustments.
Image to PDF & Page Tools Organize, reorder, and compile multiple images or PDF pages seamlessly offline.
macOS Help

How to Choose the Right Mac Package

Macs use two completely different chip architectures. Installing the matching package ensures maximum speed and efficiency.

1

Open “About This Mac”

Click the Apple menu () in the top-left corner of your screen, then select About This Mac.

2

Check your Chip or Processor

Look at the line labeled Chip or Processor in the system window:

If it says “Apple M1, M2, M3, M4...” Choose Apple Silicon (arm64)
If it says “Intel Core i5, i7, i9...” Choose Intel (x64)
3

Bypassing the Unidentified Developer Prompt

Because FilePetal is a community open-source project without Apple Developer notarization, macOS Gatekeeper may display a security alert on first launch.

  1. In Finder, Right-click (or Control-click) FilePetal.app.
  2. Click Open from the context menu.
  3. Click Open in the confirmation dialog.
  4. Alternatively, open Terminal and run: xattr -cr /Applications/FilePetal.app

Local Processing Only

Every conversion, resize, audio normalization, and metadata removal runs exclusively on your local CPU and GPU. No files are uploaded to remote servers or cloud services.

Zero Analytics & Tracking

The desktop application contains zero telemetry, zero analytics libraries, zero tracking cookies, and no mandatory account sign-up. What you do with your files is strictly your business.

Non-Destructive Operations

Original files remain completely untouched. Output files are written as new files alongside your source with intelligent collision protection (e.g. report 2.txt).

Frequently Asked Questions

Does FilePetal require an internet connection? +

No. FilePetal is built offline-first. All conversion engines (Pillow, FFmpeg, pypdfium2, etc.) are bundled directly into the application and operate entirely offline on your computer.

Why are the macOS packages not signed with Apple? +

FilePetal is a community-driven, non-commercial open-source project. Apple Developer code-signing and notarization certificates require an ongoing paid subscription. You can safely launch the app by right-clicking it in Finder and selecting Open, or running xattr -cr /Applications/FilePetal.app.

What Linux distributions are supported? +

The Linux package targets Ubuntu 22.04 LTS or newer with glibc 2.34+ on x86_64 / x64. It runs on compatible Linux distributions (Debian 12, Fedora 36+, Arch Linux, Linux Mint) under both X11 and Wayland desktop sessions.

Are download counts real people? +

No. The numbers shown on this website are raw cumulative asset downloads fetched directly from the public GitHub Releases API. They measure total asset download requests and do not represent unique individuals or active installations.

How does FilePetal prevent accidental overwrites? +

FilePetal writes every converted or edited file to a new target path beside the original. If a file with that name already exists, FilePetal automatically appends an incrementing counter (e.g., image 2.png). Incomplete jobs write to temporary files first so a failed conversion never leaves corrupted data.

What license is FilePetal released under? +

FilePetal is open-source software licensed under the permissive MIT License. Bundled third-party libraries (such as FFmpeg and Qt) have their respective licenses documented in the repository's docs/third-party-notices.md.
