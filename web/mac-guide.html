macOS setup

Pick the build for your Mac.

FilePetal provides separate ZIPs for Apple silicon and Intel Macs. You can check the processor in About This Mac.

01

Check the processor

Open the Apple menu  and choose About This Mac. Find the Chip or Processor line.

Apple M1, M2, M3, or M4
Download the Apple silicon (arm64) build.
Intel Core processor
Download the Intel (x64) build.
02

Extract the app

Open the ZIP, then move FilePetal.app to Applications or another folder you can write to.

03

Open it the first time

The community builds are not signed or notarized with an Apple Developer ID, so macOS may block the first launch.

  1. In Finder, Control-click FilePetal.app.
  2. Choose Open, then confirm Open in the dialog.

FilePetal’s macOS version uses a companion window: drop files there, choose Convert, Tools, or Actions, then pick an option.
